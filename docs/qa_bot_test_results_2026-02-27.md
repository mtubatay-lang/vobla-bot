## Анализ

### Вопросы с ответом (скорее всего есть в KB / Kilbil)

- **Документы арендатора** — релевантность высокая, явно есть в регламенте/FAQ.
- **Образец заявления на возврат** — RAG дал информацию про акт возврата (возможно, другой документ, но полезно).
- **Холодильники, рыба и сыр** — хорошо попало в FAQ/регламент по оборудованию.
- **Номенклатура в кассовом планшете** — попало в Kilbil Help (help.kilbil.ru).

### Вопросы без ответа (вероятно нет в KB или weak match)

1. **Сертификаты** — специфика франшизы; данных может не быть в регламенте.
2. **Ведение кассы** (смены, X-отчёт) — возможно есть в Kilbil, но формулировка «в целом» слишком широкая.
3. **Бонусная карта без ТГ** — edge case, возможно не покрыт.
4. **Порядковость документов в кассе** — техническая деталь, может отсутствовать в KB.
5. **Роялти и сигареты** — вопрос по франчайзингу; данных может не быть.
6. **Прайс Балтики** — операционный вопрос (где взять файл), скорее не в регламенте.

### Рекомендации

1. **Добавить в KB:** сертификаты (номиналы, оформление), основы ведения кассы (смены, X-отчёт), порядковость документов, роялти и сигареты.
2. **Расширить FAQ:** бонусная карта для пользователей без смартфона/Telegram.
3. **Прайсы:** если есть единый источник прайсов (например, ссылка/папка), добавить в FAQ или регламент.
4. **Формулировки:** для вопросов «в целом» (касса, документы) — улучшить chunking/перефразирование, чтобы широкие запросы лучше матчились с узкими фрагментами.
