# Ручные сценарии: ответ бота на вопросы в групповом чате (RAG)

Чек-лист для проверки функции ответа на вопросы в группе. Один вопрос — одно сообщение; после каждого ждём ответ бота (или отсутствие ответа) и фиксируем результат.

## Порядок прогона

1. Чат для тестов: группа «Тест группа», entity в MCP Telegram = **`"3377597100"`**.
2. По одному сообщению: отправить вопрос через MCP Telegram `send_message` (entity: `"3377597100"`).
3. Подождать 15–20 секунд.
4. Вызвать `get_messages` (entity: `"3377597100"`, limit: 8–10) — проверить, есть ли ответ бота после вашего сообщения.
5. При необходимости запросить логи Railway (`get-logs`, deploy, service vobla-bot, lines 50–100), отфильтровать по `[GROUP_CHAT_QA]`, `rag_pipeline`, `kb_search_performed` — зафиксировать outcome, top_score.
6. Заполнить колонку «Факт» и «Примечание» в таблице ниже.
